# README screenshots

Captured September 27, 2026 from the Spectarr frontend using the running demo library:

- `spectarr-release-project.png`: the demo project's three acquisitions and experiment navigation at 1440 × 850.
- `spectarr-release-spectra.png`: the Angiotensin CID benchmark, its indexed mzML derivative, chromatogram, and spectrum. The scan maximum is set to 3 through the normal filter control.

These are browser screenshots with live API responses. The frontend preview includes the Spectarr display-name changes. A temporary read-only forwarding session retrieves the backend responses for the preview, without changing their content. The existing server and demo data were not modified.

Older screenshots in this directory belong to their historical review reports and may show the previous interface or display name.
